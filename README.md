# YouTube Video Downloader

A YouTube video downloader web app (work in progress).

## Status

Early stage: the React UI components (`HomePage`, `AdminPanel`) and a Supabase Edge Function (`video-info`) are in the repo, but `App.tsx` does not use them yet.

## Tech

React, TypeScript, Vite, Tailwind CSS, Supabase.

## Run locally

```bash
npm install
npm run dev
```
